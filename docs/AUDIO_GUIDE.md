# 語音與音效規範

## 首版現況
- 題目單字和簡短指令由瀏覽器 SpeechSynthesis 輸出，選擇 zh-TW 聲音，找不到時嘗試 zh 類別聲音。
- 不同作業系統、瀏覽器、語音包會產生不同聲線及發音效果；它不是保證正確的真人錄音。
- 星星回饋為 Web Audio 簡短合成提示音，只代表遊戲回饋，不代表聲調答案。
- 遊戲內有音訊開關和重播按鈕；若瀏覽器沒有中文語音，會提示家長檢查裝置語音設定。

## 真人錄音替換計畫（尚未接入）
待取得並校驗商用授權錄音後，建議按單字 ID 放入 `public/audio/words/<id>.mp3`，題庫增加 `audio` 欄位，再由 AudioManager 優先播放檔案、失敗時清楚回退到裝置語音。錄音需有台灣國語教師或語言專業人員檢核字音、聲調、語速、音量及版權文件。不可拉長、變調或套濾鏡把錄音冒充另一個聲調。
