# 遊戲設計：聲調精靈冒險島

## 產品定位
- 年齡：4–7 歲；主要平台：桌面與行動瀏覽器。
- 核心學習：聽辨台灣華語一至四聲，連結耳朵、聲調走勢和注音。
- 單次遊玩：約 5–10 分鐘。答錯不受罰。
- 個人進度留在本機，不建立兒童帳號、不傳送遊玩資料。

## 本次範圍：P0 + P1
P1 是一個可從主畫面開始、完成十題、看見星星結算並返回重玩的完整垂直切片。主角小龍在分層森林場景裡陪伴孩子。每題先播放單字，孩子在單一魔法區由左往右畫音高路線。成功時小龍跳躍、星光出現、得到星星；失誤時顯示注音和正確路線，讀音可重播後再畫。沒有四選一聲調按鈕。

幼幼模式顯示淡金示範路線；標準模式可以隨時按示範；挑戰模式不預先示範，失誤後仍會顯示教學路線。三種模式在首版都不限時。結束後打開固定獎勵寶箱並記錄本機累積星星及各聲調首次作答數據。

## 明確限制
目前採用 Phaser Canvas 繪製的原創簡化角色及背景，尚非專業動畫素材。語音使用瀏覽器 SpeechSynthesis；聲線依裝置變動，沒有校驗過的真人錄音。本階段不是已可商業販售的產品。
