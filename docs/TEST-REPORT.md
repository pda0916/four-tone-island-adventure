# 聲調守衛戰更新紀錄
- 新增四張不同路線地圖，每張地圖提供 12 個防禦塔位置。
- 關卡波數依序為 3、6、9、12；第一關每波 2 隻慢速怪，後續增加速度和怪物數量。
- 每關最後一波最後一隻為大魔王，具有較多血量、不同大型圖案及紅色血條；四張地圖各自使用不同怪物圖案組。
- 點擊已放置的防禦塔可升級、改成四種聲調或出售回收金幣。
- `npm run build`：本次修改後 Vite 建置通過。GitHub 部署流程將執行既有四項邏輯測試。
- 尚未實機測試 iPhone/Android，也尚未由國語教師校對所有注音和字音。

- 子彈改為以地圖為座標基準追蹤怪物，並使用聲調塔對應的圖案與顏色。

- 怪物出現時會播放字音與一至四聲提示，並受音效開關控制。
