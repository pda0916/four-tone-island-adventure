# 聲調守衛戰更新紀錄
- 首頁直接選擇四個關卡；結束畫面可重玩或回到選關畫面。
- 四張不同路線地圖的塔位分別為 5、7、9、12 格。
- 四關波數為 3、6、9、12；第 4 關提高到每波 7 隻、1.9 秒出怪、速度 0.038，最終大魔王血量再提高。
- 金幣使用瀏覽器 localStorage 累積保存，跨關及重新開啟後保留。
- 每次開始或重玩關卡，金幣餘額至少補到 120；較高的累積金額照常保留。
- 子彈改用塔與怪物的 DOM 畫面中心作為座標，逐幀追蹤怪物位置，並顯示塔種對應圖案。
- 怪物出現時朗讀字音和聲調；無中文語音時顯示提醒。
- 語音改為依序播放，不再因下一隻怪物出現就取消前一句，並等待瀏覽器載入中文語音。
- 優先使用裝置提供的 zh-TW 自然／神經語音，語速調整為較接近日常說話。
- 第 1、3 關起始路段下移，為注音標籤留出上方空間。
- 200 題中 189 題改用教育部原始單字錄音，依序播放原始錄音片段組成聲調提示；11 題沒有對應單字音檔時才使用瀏覽器語音。
- 語音改為逐字念「米是三聲米」，錄音逐題排隊播完，避免被下一隻怪物打斷。
- 網頁標題改為「聲調守衛戰｜注音聲調塔防遊戲」。
- 已移除防禦塔出售功能，仍可免費更換聲調及升級。
- 怪物抵達城堡時立即更新愛心數；語音改為「米是三聲米」並依序播完。
- 題庫擴充至 200 個不同國字，每張字卡附有注音與聲調，首頁顯示題庫字數。
- `npm run build`：修改後 Vite 建置成功。部署流程會執行現有邏輯測試。
