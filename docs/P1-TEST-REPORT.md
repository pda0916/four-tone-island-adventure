# P1 聽力森林測試記錄

測試日期：2026-11-06  
交付階段：P0 專案基礎 + P1 垂直切片

## 自動化檢查

- `npm test`：5 項 Vitest 測試通過。
- `npm run build`：TypeScript 專案檢查及 Vite production build 通過。
- `npm audit --audit-level=moderate`：0 vulnerabilities。
- 10 題的種子題序、四聲手勢辨認、短線無效、錯一次後重試、星星計數、本機保存和首次作答統計由自動測試覆蓋。

## 瀏覽器實際操作

- 桌面瀏覽器：開始關卡、沿示範線畫出二聲並得到星星；故意畫錯一聲後顯示四聲文字／注音與下降路線，星星不扣；改畫正確路線後得到星星並自動進下一題。
- 390×844 瀏覽器視窗：主畫面、模式鈕、森林場景均未溢出畫面；觸控模擬下畫出上升路線得到星星；返回地圖後已收星數仍留存。
- 畫面只有一個自由繪線區，沒有四個聲調答案按鈕。
- 畫面繪線為單次直線操作，曲線聲調則由自動化幾何測試確認；真實手機、iPad、iPhone、Android 實機尚未測試。

## 已知限制及未驗收項目

- 瀏覽器語音合成受裝置語音套件影響，尚無經台灣國語教師覆核的真人錄音。
- 主角與場景由 Phaser 圖形程式繪製，屬可玩原型，未達專業商業美術規格。
- 尚未邀請幼兒試玩，也未在真實手機和平板測試效能；30 FPS 目標未實測。
- P2 過山車、怪獸餵食、世界地圖；P3 收藏；P4 錯題複習與完整家長報告均未製作。
- 注音與讀音仍需教育專業人員逐項覆核後才能作正式教學或商業發行。
