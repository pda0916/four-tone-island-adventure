聲調精靈冒險島｜P1 聽力森林

Windows 執行：
1. 安裝 Node.js 20.19 以上版本。
2. 在專案資料夾開啟 PowerShell，輸入 npm install。
3. 輸入 npm run dev -- --host 127.0.0.1，再開啟終端機顯示的本機網址。
4. 要產生上線檔案，輸入 npm run build；成品在 dist 資料夾。

玩法：選擇幼幼、標準或挑戰，聽小龍唸單字，在森林光圈內由左往右畫出聲調。答錯不扣星，會看到注音和聲調示範；答對收星，十題後結算。遊戲沒有四選一聲調按鈕。左上角可以回主畫面，右上角控制聲音；星星會立即存在本機瀏覽器。

九個單字題目都有隨遊戲附上的合成示範音，不需裝置支援中文語音。簡短語音說明則使用瀏覽器提供的中文語音，沒有時仍可重聽題目示範音。目前尚無經校驗的真人錄音。

目前完成 P0 專案基礎及 P1 聽力森林。過山車、怪獸配對、精靈收藏及錯題複習尚未開發。此版本是可玩原型，不是商業成品。詳見 README.md 與 docs 資料夾。
