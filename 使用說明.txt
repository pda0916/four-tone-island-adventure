# 雲朵聲音郵局
直接雙擊 index.html，或開啟 https://pda0916.github.io/four-tone-island-adventure/ 。
選「出發送四封信」會隨機安排四個不同的站；也可自由挑一站練三封信。
風車分信所：聽音後拖曳信件到郵筒，或先點信、再點郵筒。
雲海飛行隊：拖動飛船到亮起的光圈放手，也可用升降和穿圈按鈕。
山谷音樂館：聽完字音，跟著亮起的低、中、高音鐘敲三下。
月光投遞站：翻開同聲調的字信與郵戳，配出兩對。
每封完成的信獲得一枚郵戳。重練字卡在不同趟旅程首次作對兩次後移出。
29 個單字使用內嵌的台灣中文合成示範音，非真人錄音。指令旁白視裝置有無台灣中文語音而定。
進度存在本機瀏覽器，不需要登入。npm test 執行互動邏輯測試，npm run build 產生部署內容。
