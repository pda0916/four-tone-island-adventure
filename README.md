# 狐狸聲調跳島
全新 Canvas 橫向冒險遊戲，取代原本的 P1 聽力森林。舊版封存在工作區 before-fox-redesign.zip 和 Git 歷史。

## 遊玩
雙擊 index.html，或進入 https://pda0916.github.io/four-tone-island-adventure/ 。九段單字音已嵌入 HTML，不需要網路、CDN 或安裝工具。
- 四座島直接開放；每座島三座橋，修好後走到城堡開寶箱。
- 電腦：方向鍵走路，空白鍵或上方向鍵跳躍。
- 手機：點左右鈕自動走，再點同方向停下；上箭頭跳躍。
- 石碑描線：聽單字後，從左至右沿聲調路線畫橋。
- 精靈補給：把字卡果實拖到精靈身上。
- 答錯不扣星，錯字進入錯題探險；不同探險輪次答對兩次後移出。
- 星星、島嶼精靈、家長首答統計存於本機 localStorage。

## 聲音與限制
九段單字是合成語音，未經國語教師逐檔覆核，並非真人錄音。只有九個示範字，尚無五千字題庫。指令旁白使用裝置 zh-TW / 中文語音；裝置沒有中文語音時仍有單字 MP3 和畫面引導，沒有完整指令旁白。音樂與音效可關閉。配對補給任務是操作教學，並非四聲聽辨測驗；畫橋有提示路線，偏向聲調入門。
目前四座島採相同冒險架構、依聲調改變學習路線，沒有加入過山車或隨機抽獎。
真實 iPhone / iPad 尚未實機驗收。使用本機檔案時，瀏覽器可能限制 localStorage，不能跨裝置同步；進度不會上傳。

## 開發
原生 HTML / CSS / JavaScript；Vite 只用於部署包裝。npm ci、npm test、npm run build。測試使用 Node 內建測試器，包含四島物理流程、首答與重試、跨輪錯題、描線及拖曳判定。
替換語音：在 index.html 的 AUDIO 物件中替換相應 data:audio/mpeg;base64 內容；也可將值改為相對 MP3 路徑，並隨 HTML 保存該檔案。
