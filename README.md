# 四聲島大冒險

給孩子練習注音四聲的中文遊戲。六座島、三十個關卡、自然台灣中文慢速朗讀、狐狸射擊聲調氣球、聲調小課與 4,808 字國字圖鑑都在同一個網站中。

## 開始遊戲

在瀏覽器開啟 index.html。每題狐狸會用語音念出詞語和目標字，並把辨聽提示帶入本題；每個字右側會直列顯示注音，揭曉後聲調符號會放在注音中段旁邊。狐狸只在第一題說一次開場白，作答前會結合本題詞語和目標字引導聆聽，答題後再用本題示範該字的聲調；答對時狐狸會沿著十階樓梯往下走，答錯時會醒目提示正解。聲調教室使用自然台灣中文語音朗讀課文，也可以重播。孩子聽完後選擇上方的氣球；狐狸站在下方射出星星。射中正確聲調可得分，所有關卡都能直接選擇，每關答對七題即可通關。遊戲進度存在目前瀏覽器的本機儲存空間。

## 檔案

- index.html：遊戲頁面
- styles.css：場景動畫、射擊與關卡版面
- app.js：關卡、朗讀、答題、射擊動畫與圖鑑互動
- vocabulary.js：遊戲詞語和讀音
- audio.js、audio/：慢速自然語音朗讀和音效
- characters.js：教育部 4,808 個常用字圖鑑讀音資料
- lessons.js：38 堂聲調課，約 5,975 個中文字
- 使用說明.txt：本機操作方式
- 資料來源.txt：字表與讀音資料來源

課綱規定不同學習階段的識字量目標，並未逐字列出唯一的國小必學字清單。本遊戲將 4,808 字常用字表作為可搜尋字庫，關卡則依聲調難度安排。
