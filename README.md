# 聲調守衛戰
首頁可直接選擇四張地圖的任一關卡，不必解鎖；通關或失敗後可回到選關畫面。
四張地圖路線和怪物圖案各不相同，塔位會逐關增加：第 1 關 5 格、第 2 關 7 格、第 3 關 9 格、第 4 關 12 格。
關卡波數依序為 3、6、9、12；每波怪物依關卡為 3、5、7、9 隻。怪物基礎移動速度整體放慢約 25%，每關內仍每波增加 2.5%（最多 30%）、怪物血量每波累乘增加 20%、出怪間隔每波縮短 0.1 秒（最低 1.4 秒）；第 2 波起加入快跑怪，第 4 波起混入厚血怪，最後一波最後一隻是大魔王。第一關最慢且怪物稀疏；第 4 關出怪間隔較短、速度更快，最後一波的大魔王血量也較高。
拖曳四種聲調塔到空位；手機可點塔，再點空位。防禦塔只能攻擊相同聲調的怪物，聲調不符時不會造成傷害。點已放置的塔可升級或免費更換聲調。子彈以塔和怪物的實際畫面座標逐幀追蹤移動中的目標，圖案和顏色配合防禦塔。
金幣會跨波、跨關、回到選關畫面和重新開啟網站後累積保留，資料存在瀏覽器 localStorage；每次重新開始或進入關卡時至少有 1000 枚金幣，跨入新地圖另有建塔補給。
題庫目前有 200 個不同國字，每張字卡附注音與聲調；開始遊戲時立即播放第一題，之後只用裝置語音說明「米是三聲米」，不播放包含部首或筆畫資訊的字典音檔。語音種類取決於裝置可用的 zh-TW 語音；可在 index.html 的 cards 陣列編輯題庫。
本版使用原創風格怪物圖示，未載入寶可夢角色或圖像。
直接雙擊 index.html 可離線遊玩。`npm test` 為四項塔防邏輯測試；`npm run build` 建置網站部署檔。
