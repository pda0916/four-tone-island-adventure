# 聲調守衛戰
注音聲調塔防遊戲，可直接雙擊 index.html 或開啟 GitHub Pages。
四個關卡使用四張不同路線地圖，每張地圖有 12 個防禦塔位置；點已放置的塔可升級、免費更換聲調或出售（回收部分金幣）。
各關波數依序為 3、6、9、12。第一關最慢且怪物稀疏，後續逐關增加移動速度和每波怪物數量。每關最後一波最後一隻是高血量大魔王，四張地圖各有專屬小怪、快怪、厚血怪和大魔王圖案。
拖曳四種聲調塔到地圖上的空位；觸控螢幕可點塔，再點空位。防禦塔會自動攻擊附近怪物。子彈會沿著戰場座標飛向怪物，並使用對應聲調塔的圖案和顏色。對的聲調命中 10 點，其他塔命中 1 點。
開始有 140 枚金幣與 10 點生命，打倒怪物獲得金幣。每次進入新地圖會回收既有防禦塔並補給 100 枚建塔金幣。通過 4 張地圖共 30 波怪物後過關。
20 張單音節題卡，包含ㄇㄚ、ㄉㄧㄢ等四聲練習。此版尚未加入雙字詞；題庫可在 index.html 的 cards 陣列編輯擴充。
瀏覽器具備 zh-TW 語音時可朗讀簡短指令；攻擊音效為 Web Audio 合成音。
npm test 執行 4 項塔防邏輯測試；npm run build 產生網站部署檔。
