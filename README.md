# 四聲島大冒險

給孩子練習注音四聲的中文學習遊戲。六座島、三十個關卡、詞語聽辨、聲調小課與國字圖鑑都在同一個離線單頁網站中。

## 開始遊戲

在瀏覽器開啟 `index.html`。遊戲進度存在目前瀏覽器的本機儲存空間；朗讀使用瀏覽器的中文語音功能。

## 檔案

- `index.html`：遊戲頁面
- `styles.css`：場景、角色與關卡版面
- `app.js`：關卡、答題、進度與圖鑑互動
- `vocabulary.js`：遊戲詞語和讀音
- `characters.js`：教育部 4,808 個常用字圖鑑讀音資料
- `lessons.js`：38 堂聲調課，約 5,975 個中文字
- `使用說明.txt`：本機操作方式
- `資料來源.txt`：字表與讀音資料來源

課綱規定不同學習階段的識字量目標，並未逐字列出唯一的國小必學字清單。本遊戲將 4,808 字常用字表作為可搜尋字庫，關卡則依聲調難度安排。
