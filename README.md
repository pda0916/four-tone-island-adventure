# 聲調精靈冒險島

雙擊 index.html 即可開始。HTML、CSS、原生 JavaScript、SVG 角色與九段預錄語音都在同一檔案，不需安裝、編譯或 CDN。原版程式已被新版架構取代。

## 五大系統

- 聽力森林：幼幼二選一，標準／挑戰四選一。可重聽重試，連續三題首次答對有魔法效果。
- 彩虹過山車：小車沿實際 SVG 路徑前進；挑戰模式沿軌道推車，另有鍵盤和示範協助。
- 怪獸餵食屋：滑鼠／觸控拖動字卡，或先點字卡再點怪獸。錯誤時重播發音並示範聲調。
- 寶箱與收藏：每題得星星，完成一回有寶箱，未開寶箱保留。獎勵依序取得，沒有抽獎、廣告或付費。四精靈收齊可進城堡；帽子、皇冠和披風可穿戴。
- 錯題島：保存首次作答、混淆聲調與錯題。不同回合首次答對兩次才暫時畢業；當回錯後重試不計畢業。後續會加入相同聲調的其他字。

幼幼每回5題、標準和挑戰每回10題，不強制計時。主要玩法各有三關，全部開放。初期32張單字、八組同音節四聲，包括媽麻馬罵、八拔把爸。初期採獨立單字第三聲；挑戰加入詞語語境，先示範詞語再單獨念目標字，依其本調作答。

## 聲音來源與限制

內建九段台灣中文預錄合成語音，不是已校音真人錄音。其他字和解說使用 SpeechSynthesis，優先 zh-TW；不可用或播放失敗會提示。音高軌道示範為純音效，與國語發音分開。沒有變速或變調單一錄音來假裝四聲。

語音尚未經台灣國語教師逐字校音。程式播放測試不等於語音學驗證。建議家長逐字確認，並匯入已校音真人錄音。裝置的部分合成語音可能需要網路；離線可用性依裝置而異。

## 真人錄音擴充

方式一：家長專區選字卡、匯入音檔，確認是真人且發音正確。建議1～3秒MP3、小於300KB，上限600KB。只保存在此瀏覽器，容量不足有提示。

方式二：放入 audio/ma1.mp3 等檔案，在 index.html 搜尋 const VOICE_OVERRIDES，改成：

```js
const VOICE_OVERRIDES = {
  '媽': {src:'audio/ma1.mp3',kind:'human',verified:true},
  '麻': {src:'audio/ma2.mp3',kind:'human',verified:true},
  '馬': {src:'audio/ma3.mp3',kind:'human',verified:true},
  '罵': {src:'audio/ma4.mp3',kind:'human',verified:true}
};
```

只有確實完成校音的真人錄音才能標記 human 和 verified:true。保留相對位置即可整包離線使用。
播放優先：家長匯入 → VOICE_OVERRIDES → 內建預錄合成語音 → 裝置中文語音。
原專案保留的其他音檔不會自動載入。

## 本機進度與報告

家長區顯示完成題數、各聲調首次正確率、混淆矩陣、錯題複習及關卡完成情況。重試不會墊高首次正確率。有家長數學題和再次重設確認。可匯出JSON報告；重設進度不刪除真人錄音。

只使用localStorage，不登入、不傳送兒童資料。進度鍵 lunaSpiritAdventureV1，錄音鍵 lunaSpiritRecordingsV1。不同裝置、瀏覽器、網址或本機檔案路徑不會同步；無痕或清除網站資料可能移除進度。儲存被禁止時會提示。
