# 聲調守衛戰
首頁可直接選擇四張地圖的任一關卡，不必解鎖；通關或失敗後可回到選關畫面。
四張地圖路線和怪物圖案各不相同，塔位會逐關增加：第 1 關 5 格、第 2 關 7 格、第 3 關 9 格、第 4 關 12 格。
關卡波數依序為 3、6、9、12。第一關最慢且怪物稀疏；第 4 關每波 7 隻、每 1.9 秒出怪、速度明顯提高，最後的大魔王血量也大幅增加。每關最後一波最後一隻是高血量大魔王。
拖曳四種聲調塔到空位；手機可點塔，再點空位。點已放置的塔可升級或免費更換聲調。子彈以塔和怪物的實際畫面座標逐幀追蹤移動中的目標，圖案和顏色配合防禦塔。
金幣會跨波、跨關、回到選關畫面和重新開啟網站後累積保留，資料存在瀏覽器 localStorage；每次重新開始或進入關卡時至少有 120 枚金幣，跨入新地圖另有建塔補給。
題庫目前有 200 個不同國字，每張字卡附注音與聲調；怪物出現時播放「米是三聲米」格式的逐字錄音，並排隊播完每一題。189 個字使用教育部原始單字錄音，另外 11 個沒有對應錄音的字才使用裝置中文語音。WAV 原檔放在 `public/assets/moe-audio/`，授權與出處見 `public/assets/moe-audio/CREDITS.txt`；可在 index.html 的 cards 陣列編輯題庫。
本版使用原創風格怪物圖示，未載入寶可夢角色或圖像。
直接雙擊 index.html 可離線遊玩。`npm test` 為四項塔防邏輯測試；`npm run build` 建置網站部署檔。
