# 聲調精靈冒險島｜P1 聽力森林

這是以 Phaser 4、TypeScript、Vite 製作的第一關可玩版本。孩子陪小龍在森林裡聽國語單字，並用手指或滑鼠畫出聲調路線。答錯會看到提示後重試，答對得到星星。**遊戲沒有四選一聲調按鈕。**

## 在 Windows 執行

1. 安裝 Node.js 20.19+ 或 22.12+。
2. 在專案資料夾開啟 PowerShell，執行 `npm install`。
3. 執行 `npm run dev -- --host 127.0.0.1`，以終端機顯示的網址開啟遊戲。
4. 發佈建置：`npm run build`；本機預覽：`npm run preview`。

遊戲需要 Vite 開發伺服器或靜態網站伺服器，不能直接雙擊 `index.html`。`npm run build` 會將可部署檔案輸出到 `dist/`。

## 操作

- 選幼幼、標準或挑戰，再按「開始冒險」。
- 聽小龍唸字後，在大光圈內由左往右畫出聲調。
- 按「重聽」重播；幼幼模式會顯示淡金示範線，其他模式可按「示範」。
- 答錯不扣星星，注音和正確路線會出現；答對收集星星，十題後結算。
- 左上角按鈕返回主畫面；右上角調整音訊。小鍵盤空白鍵／上鍵可讓小龍跳躍。

## 資料夾

- `src/scenes/`：Phaser 場景與互動。
- `src/data/`：單字資料、手勢辨識和單元測試。
- `src/systems/`：音訊及本機進度。
- `docs/`：設計、聲音、美術、QA 規範。
- `public/`：正式發音檔的預留位置（尚無經校驗的真人錄音）。

## 語音與品質狀態

目前字音使用瀏覽器提供的語音合成；聲音依裝置而異，不是已錄製或人工校驗的真人語音。若裝置沒有中文語音，遊戲會提示家長檢查語音設定。聲調注音資料仍需由台灣國語及注音專業人員正式校對，才能用於商業發行。

本次交付只有 P0 基礎和 P1 聽力森林。過山車、怪獸配對、精靈收藏、錯題間隔複習等屬 P2–P4，尚未實作。此原型不是商業品質成品。
