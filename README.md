# 聲調守衛戰
注音聲調塔防遊戲，可直接雙擊 index.html 或開啟 GitHub Pages。
拖曳四種聲調塔到地圖上的空位；觸控螢幕可點塔，再點空位。防禦塔會自動攻擊附近怪物。點已放好的塔可花金幣升級，最高三級。
每隻怪物頭上顯示單字與聲調符號。對的聲調命中 10 點，其他塔命中 1 點。普通怪、快跑怪、厚血怪交替出現；怪物到城堡會扣一顆生命。
開始有 140 枚金幣與 10 點生命，打倒怪物獲得金幣。連續正確攻擊也有加成。擊退三波過關，生命歸零則需要重玩。
20 張單音節題卡，包含ㄇㄚ、ㄉㄧㄢ等四聲練習。此版尚未加入雙字詞；題庫可在 index.html 的 cards 陣列編輯擴充。
瀏覽器具備 zh-TW 語音時可朗讀簡短指令；攻擊音效為 Web Audio 合成音。
npm test 執行 4 項塔防邏輯測試；npm run build 產生網站部署檔。
